# 同模幻化浏览器

在试穿装备时，帮你找出外观相同的其他装备。

支持普通试穿、投影模板和幻化柜。找到结果后，点击物品图标，就会在聊天框的默语（`/e`）中显示该装备的可点击物品链接，方便继续查看和比较。

## 安装

在 Dalamud 的插件安装器中添加下面的自定义仓库地址，然后搜索“同模幻化浏览器”安装：

```text
https://raw.githubusercontent.com/EITecYi/GlamourModelBrowser/main/repo.json
```

仓库文件也可以在 GitHub 查看：[repo.json](https://github.com/EITecYi/GlamourModelBrowser/blob/main/repo.json)。

## 怎么用

1. 在游戏里打开一件装备的**试穿**界面。
2. 点击试穿窗口上方的 **同模** 按钮。
3. 在打开的列表里查看同模型装备；列表中的第一类结果也会包含当前正在试穿的装备本身。

如果没有看到“同模”按钮，也可以在聊天栏输入：

```text
/gmb
```

然后点击窗口中的“刷新当前试穿”。

## 可以在哪些地方使用

- 普通试穿窗口
- 投影模板
- 幻化柜

在幻化柜中，建议先对物品使用“试穿”。如果只是选中了物品而没有打开试穿窗口，也可以打开 `/gmb` 后点击“刷新当前试穿”。

## 查看和比较装备

- 列表会显示同模型装备的名称和图标。
- 点击图标，会在默语频道显示对应的物品链接。
- 可以使用窗口中的名称筛选，快速缩小结果范围。
- 顶部的“同模：X 件（含本装备）”表示当前结果数量，本装备也计算在内。

## 常见情况

**点了“同模”却没有结果？**

先确认正在打开游戏原生的试穿、投影模板或幻化柜界面，然后在插件窗口点击“刷新当前试穿”。首次使用时需要建立本地物品索引，稍等片刻再看结果。

**找到了装备，但点击图标后没有看到链接？**

检查聊天框是否正常显示默语（`/e`）消息。插件显示的是游戏内可点击物品链接，不会替你发送普通聊天内容。

**为什么某些结果和网站不完全一样？**

插件只使用你电脑中《最终幻想 XIV》客户端自带的物品数据来判断模型，不会访问 Wiki、Garland Tools 或其他网站。它用于快速找外观相同或高度接近的装备；个别特殊装备的结果可能与第三方网站的人工整理不同。

## 隐私与数据

插件不会上传角色、聊天或账号信息，也不会在运行时查询外部物品数据库。
