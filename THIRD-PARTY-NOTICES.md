## Garland Tools model-grouping approach

This project independently implements a local equipment model grouping approach
inspired by the publicly available Garland Tools data builder:

- Project: <https://github.com/ufx/GarlandTools>
- Relevant source: `Garland.Data/Modules/Items.cs`
- Copyright: Copyright (c) 2018 Chris Faulhaber
- License: MIT License

The plugin does **not** copy, download, scrape, embed, or redistribute data from
Garland Tools websites, including `garlandtools.cn`. It reads only the player's
own local FFXIV `Item` sheet at runtime.
